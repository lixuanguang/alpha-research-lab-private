B06 repository-local integration and security evidence

Scope: Bazel, installed command, Make, pre-commit, hosted workflow, secret handling, and docs.
Result: passed.

The remote lane is guarded to a main push and an explicit repository variable. Pull-request
code cannot select it. The credential exists only as a protected environment secret, is
validated without disclosure, is written to a mode-0600 temporary Bazel rc, is removed from
the child environment, and is deleted after the command. Workspace credential helpers and
committed remote headers are prohibited. Remote failure is visible because in-lane local
fallback is disabled; disabling the guarded lane restores the verified local path.

Independent review, provisioned control-plane configuration, credential rotation/revocation,
and B07 dependency admission remain B06-F01 through B06-F03.
